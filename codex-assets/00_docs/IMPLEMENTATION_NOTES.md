# 素材使用补充说明

## 1. 关于 Document Description 中的错字/歧义
- 04 e神页的说明里写到 INFJ/INFP 等属于 i神组，这是说明文本笔误；实际文件与分组以 `04_e_mbti_select_assets/e_group/cards/` 和 `11_data/mbti_grouping.csv` 为准。
- 10 最终保存卡对应 07 签文纸时，统一按“同 MBTI + 同编号”对应，例如：
  - `07-oracle-paper-ENFJ-01.png` → `10-deity-ENFJ-01.png`
  - `07-oracle-paper-INTJ-03.png` → `10-deity-INTJ-03.png`

## 2. 关于当前素材完整度
目前完整下游资产主要覆盖 8 个 MBTI：ENFJ、ENTJ、ENTP、ESFJ、INFJ、INFP、INTJ、INTP。
其他 MBTI 有选择页牌子或首页素材，但缺少详情页/签文页/保存页完整预设。Codex 实现时不得自行生成视觉资产。

## 3. 关于“再来一次”
点击“再来一次”时必须重新抽一支新的签文纸，并在签文页重新展示。不要重复验当前签文。
